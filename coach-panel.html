How a line is read

Three fields, in this order.

  1. Module — the level name, e.g. Advance (Level 1). A name that does not exist yet is created as a new module.
  2. Session number — a whole number. Left out, it carries on from the last session in that module.
  3. Topic — everything after the second separator, so a topic containing a comma is still safe.

Lines that cannot be read are listed above and skipped — nothing is imported until you press a button.

Making it live

The site is static, so a change becomes public when the file is uploaded.

  1. Press Download syllabus.json. Your browser saves the file.
  2. In cPanel → File Manager, open public_html/assets/.
  3. Upload it, replacing the syllabus.json already there.
  4. Any syllabus with a file attached needs that file in public_html/assets/syllabus/ too.
  5. Hard-refresh once. Students and the school see the new syllabus.
